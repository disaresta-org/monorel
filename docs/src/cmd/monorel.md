# Install

```sh
go install monorel.disaresta.com/cmd/monorel@latest
```

The `monorel` binary lives at `cmd/monorel/main.go` in the repo. The vanity import path resolves via the `go-import` meta tag served on this site to the canonical GitHub repository: <https://github.com/disaresta-org/monorel>.

For the full quickstart, see [Getting Started](/getting-started).
